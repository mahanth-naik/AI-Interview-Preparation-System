# AI Interview Preparation System

An AI-powered interview preparation system using LLM and RAG.

## Project Objective

The system aims to help students and job seekers prepare for interviews by analyzing their resume and target job description, generating relevant interview questions, conducting mock interviews, and providing AI-based feedback.

## Planned Features

- Resume Upload
- Job Description Analysis
- Skill Gap Identification
- RAG-based Interview Question Generation
- Conversational Mock Interview
- AI-based Answer Feedback
- Interview History and Progress Tracking

## Technologies

- LLM
- RAG
- Python
- Backend and Frontend technologies to be finalized
